# PerspectiveLab — User Guide

**Live app:** https://perspective-lab.onrender.com/

---

## Online (fastest way to try)

1. Open the live app  
2. **Create account** / Sign in  
3. **Settings → API key** — your OpenRouter or OpenAI key + model  
4. **Workspace** — write context + question → **Ask agents**  
5. Use **Compare**, **Invite**, **Report**, or **Present** as needed  

- Agents start **only** when you press **Ask agents**  
- **New problem** clears the workspace for a fresh framing  
- **Demo** mode (sidebar) is for quick sample walkthroughs  

---

## Typical research flow

**Workspace → Compare → Matrix → Invite → Report → Present**

Languages: EN / PT / FI (sidebar).

---

## Tips

- Use at least ~8 words of real context; short prompts make agents invent details  
- Free cloud hosting can be slow after idle; local runs are faster for Report/Present  
- Never share your API key; each person uses their own in Settings
